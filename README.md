📱 使用方法（v2）

上传书籍

点击或拖拽上传 TXT 文件
自动识别 UTF-8 / GBK(GB18030) / Big5 / UTF-16 编码
自动智能分章（识别"第X章"、"序章"、"Chapter N"等标题；识别失败会按字数兜底切块）

阅读和批注

划选文字 → 点"💬 批注" → 写下想法 → 保存（粉色气泡）
点 ☰ 打开目录，跳转到任意章节
翻页支持跨章节连续翻

和 Ash 的往返

点"📋 复制"：导出你的新批注为文字，发给 Ash
Ash 读完回一段 JSON：`[{"chapter":0,"index":4,"text":"..."}]`
点"💙 粘贴回复"，把这段 JSON 粘贴进去，蓝色气泡就出现了

剧情笔记

点"📝 笔记"，粘贴 Ash 写的本章剧情摘要，方便你快速回忆剧情

调整字号

点击 A− 减小字号 / A+ 增大字号

💾 数据存储

所有数据（书籍内容、批注、笔记、阅读进度）保存在浏览器本地
不需要登录，不需要网络，也不需要服务器常开
清除浏览器数据会丢失所有内容，建议定期用"复制"功能导出重要批注
